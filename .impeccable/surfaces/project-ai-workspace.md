# 项目 AI 工作区

- Mode: Operate。当前是隔离候选，现役界面合同见 [H05](../../docs/business/项目AI工作区-H05项目与任务界面.md)，运行边界见 [H04](../../docs/business/项目AI工作区-H04运行接入.md)；文件与技能未开放。
- Target: ConversationScreen、TaskBoardScreen、Composer、Sidebar、ContextSidebar；保留现有 DESIGN、字体、浅灰侧栏、白色正文、深色操作和公共组件。
- THESIS：正文、真实结果和同任务持续沟通优先，项目组织来源；不另建任务平台或组件库。
- STORY：新会话选意图 → 接受正文 → 幂等执行 → 查看结果 → 工作等待本人验收 → 验收完成 → 延伸原任务。聊天没有 task。
- ENTRY：全局新聊天默认聊天且无项目；项目内默认工作；“创建任务”进入未提交工作草稿。模式选择仅在新会话，历史会话固定；任务冻结来源和会话当前关联分开。
- SIDEBAR：项目与其会话同起点、同字号；置顶在项目上方；最近全部／聊天／工作。会话三点与图钉、项目及分组操作按悬停、键盘焦点和触屏规则显示；归档在所有日常入口隐藏。
- DETAIL CRAFT：侧栏菜单向内对齐，250px导航时缩短项目菜单，窄屏品牌及环境标识不拆行；公共Drawer仅有关闭按钮的标题区保持同一行。项目详情空文案与分组标题同左缘，项目文字跟随界面字号，编辑输入框复用8px圆角。
- TASK PANEL：状态分组、列表和运行记录共用真实数据；待执行／处理中／待跟进／待验收／已完成五列；阶段动作按状态变化，没有统一“继续工作”、暂停或拖动状态。
- TASK DETAILS：仅原320px右栏，侧栏字号与间距，默认折叠信息；选结果自动展开正文，选进度展开运行记录，共享一次运行读取。busy验收／开始／停止回执保护关闭、任务和运行切换及来源归档，包含单任务自动选择。
- EMPTY／SCROLL：空集合保留五列；空图标与列标题不同，48px灰色线条、无背景和状态色、opacity=0.4；每列至多五卡高度，超出列内渐隐滚动；列表和运行记录在自身区域滚动，窄容器按字段重排。
- CONVERSATION：安全Markdown／GFM；宽表格和代码局部横滚；紧凑可展开处理记录，不公开原始推理。发送期间不闪旧执行操作；最新失败／受阻输入用两侧细线及居中重试，停止后保留正文和下一草稿。
- CONTEXT：工作显示真实last用量环形入口及原生整理状态；整理中复用重试的两侧细线，居中灰色文档图标和「正在精简上下文」，没有按钮；停止优先，结束恢复普通处理记录。聊天后台管理但不显示窗口。不得用累计计费token代替当前上下文占用或伪造整理事件。
- SETTINGS：系统设置会话管理复用其它TAB的标题、列表、字号和滚动；名称搜索、只读查看、恢复、一次确认永久删除；不使用聊天分段控件、回收站或重复确认。
- REUSE：SegmentedControl、WorkbenchMenus、Drawer（项目／更名）、TopBar、MessageBody、tool-action、useUnsavedChanges、confirmWorkbenchLeave、PageState；业务Hook持有请求、权限、草稿、对账与操作。
- STATES：首次加载、空集合、筛选无结果、普通读取失败、模块关闭、失权、dirty及回执busy分开；任务集合403／关闭404撤销任务能力，单资源404不撤销所有任务，401保留真实身份失效语义；后台执行本身允许离开。
