# 聊天、工作与项目菜单验证记录

## 本轮目标

明确聊天与工作模式的加号职责，并为工作模式补充可选择的项目上下文。

## 最终结构

### 聊天模式

点击加号后向下打开轻量菜单：

1. 添加文件
2. 引用知识库

“添加文件”连接系统文件选择入口。“引用知识库”是可勾选的上下文开关。

### 工作模式

点击加号后向下打开完整工作菜单：

1. 添加文件
2. 引用知识库
3. 计划模式
4. 第一条轻分割线
5. 技能：需求诊断、项目状态更新、知识沉淀建议
6. 第二条轻分割线
7. 工作流：AI 需求诊断工作流、项目状态更新工作流

“引用知识库”的开关状态在聊天与工作模式之间共用。

### 项目选择

- 已选择项目时显示文件夹图标与项目名称。
- 项目按钮与文件夹图标均不使用底色，只保留项目识别色。
- 悬停已选择项目时显示移除图标。
- 移除项目后显示“选择项目”。点击后向下打开项目列表。
- 项目列表直接复用左侧项目数据：宏昊 AI 中台、部门需求治理、知识与技能。

## 验证结果

- 聊天菜单仅有“添加文件、引用知识库”两项。
- 工作菜单包含 3 个顶部操作、3 个技能、2 个工作流和 2 条分割线。
- 两个模式的“添加文件”均可打开系统文件选择入口。
- “引用知识库”切换后，在另一模式中保持相同选中状态。
- 模式切换、点击菜单外部或按 Escape 均可正确关闭浮层。
- 工作菜单、聊天菜单与项目菜单均向下展开。
- 390px 宽度下无横向溢出，工作菜单底部位于视口内。
- 桌面端工作菜单底部位于 720px 高度视口内。
- 浏览器控制台无错误和警告。
- `npm.cmd run typecheck`：通过。
- `npm.cmd run build`：通过。
