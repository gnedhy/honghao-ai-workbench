# 聊天与工作输入区 Codex 细节验证记录

## 本轮目标

统一聊天与工作模式的输入交互，并按 Codex 的克制风格细化圆角、阴影和发送按钮状态。

## 已完成

- 工作输入区使用 `+` 作为添加内容入口，不再使用回形针。
- 聊天与工作模式均移除语音入口，发送按钮只承担发送或执行含义。
- 发送按钮固定为 32px 圆形，空输入时显示灰色禁用态，输入有效文字后切换为近黑色激活态。
- 工作输入框使用 18px 圆角、冷灰细边框和双层柔和阴影。
- 聊天空状态保留 24px 胶囊圆角，适配单行输入结构。
- 聊天与工作模式均支持 Enter 提交、Shift + Enter 换行。

## 验证结果

- `npm.cmd run typecheck`：通过。
- `npm.cmd run build`：通过。
- 桌面端实测：工作输入框宽 650px、高 102px、圆角 18px；禁用按钮为 32px；无横向溢出。
- 390px 宽度实测：工作输入框宽 362px、高 102px；按钮保持 32px；无横向溢出。
- 空输入状态：发送按钮禁用且为灰色。
- 输入文字后：按钮在 150ms 颜色过渡后变为近黑色并可提交。
- 聊天与工作模式：均未发现语音控件。

## 设计取舍

发送按钮固定占位可避免输入时工具栏宽度跳动；禁用态继续呈现箭头，让用户提前理解按钮职责，同时通过灰色和不可点击状态表达当前尚不能提交。
