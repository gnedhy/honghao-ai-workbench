# 轻项目重关联验证记录

日期：2026-08-17

## 产品定义

项目是一个轻量上下文容器，用来把相关会话、任务、知识来源和受控工作目录自然放在一起。它不是独立的复杂项目管理系统，不在 V0.1 中增加成员、排期、里程碑、甘特图或多层级配置。

Skill 与 Workflow 属于企业共享能力，不归属于某个项目；项目中的任务只记录本次调用了哪些能力和版本。

## 本轮关联结果

1. 左侧项目、项目内会话、置顶/最近会话和工作输入框共享同一项目关联状态。
2. 从置顶、最近或项目子项打开已有会话时，自动恢复其项目上下文并展开对应项目。
3. 在已有工作会话中移除或重新选择项目后，会话同步移出原项目并进入新项目。
4. 单击左侧项目标题只负责展开和收起，不会误改当前会话的项目归属。
5. 任务和部分知识可显示来源项目；没有项目的个人对话和企业公共知识仍可独立存在。
6. 右侧执行控制明确说明：项目只提供上下文和受控目录，写入仍需人工确认。

## 验证结果

- TypeScript 类型检查与 Vite 生产构建：通过。
- 桌面端：打开“客服知识库优化”后自动关联“部门需求治理”；重新选择“知识与技能”后，会话从原项目移动到新项目，输入框与右栏同步更新。
- 移动端 `390 × 844`：从抽屉导航打开项目会话后，输入框正确显示项目；页面宽度 `390 / 390`，无横向溢出。
- 浏览器控制台：最终页面无新增错误或警告。

## 安全与代码审查

- 本轮只调整前端原型状态与展示数据，不新增网络请求、文件写入、权限或外部服务。
- 项目关联为可选字段，不强迫所有对话、任务和知识进入项目。
- 现阶段关联状态只存在于前端运行内存；刷新页面后回到示例数据。持久化留待后续 SQLite 数据层实现。
