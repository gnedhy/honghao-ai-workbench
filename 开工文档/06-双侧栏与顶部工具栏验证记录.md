# 双侧栏与顶部工具栏验证记录

## 本轮目标

在不改变既有信息架构和 V0.5 Codex 视觉语言的前提下，提高顶部区域的信息密度，并让左右侧栏分别承担稳定职责：

- 左侧栏：全局导航、置顶会话、最近会话与个人入口；
- 中间区：当前聊天、知识、自动化或任务内容；
- 右侧栏：当前任务、知识、Skill、Workflow 与安全边界上下文。

## 已实现

- 顶部由单一标签条改为“当前对象 + 模式标签 + 页面操作 + 上下文开关”；
- PC 端在 `1180px` 以上启用三栏布局，右侧上下文栏可随时收合；
- 中等宽度下右侧栏改为覆盖式检查栏，避免压缩主要内容；
- `760px` 以下左导航与右上下文改为互斥抽屉；
- 右侧内容随新聊天、知识、自动化、任务看板切换；
- 右侧“查看任务与运行记录”可进入任务看板；
- 修复移动端 ChangeSet 长文件路径造成的工作区内部横向滚动。

## 验证环境

- 地址：`http://127.0.0.1:4173/`
- 桌面视口：`1586 × 992`
- 移动视口：`390 × 844`
- 验证方式：宿主管理的 Browser、DOM 状态、控制台日志和截图对照

## 与 V0.5 的视觉对照

| 对照点 | V0.5 依据 | 本轮结果 |
| --- | --- | --- |
| 配色 | 浅灰蓝侧栏、纯白主画布 | 保持不变，右栏使用更浅的灰白背景区分层级 |
| 顶部控件 | 灰底分段标签、白色选中块 | 保留原有控件，只补充标题和收合入口 |
| 按钮 | 近黑主按钮、白底细边次按钮 | 新增操作沿用相同按钮体系 |

| 信息层级 | 会话内容优先 | 右栏固定为 `304px`，中心仍是视觉主区域 |
| 移动端 | 内容优先、侧栏抽屉 | 顶部两行，左右栏按需覆盖且互斥 |

## 当前边界

- 右侧上下文内容仍为原型数据，尚未与真实运行状态同步；
- 响应式行为已在 Chromium 桌面与 `390px` 移动视口验证，尚未覆盖真实触摸设备和 Safari；
- 本轮只调整前端结构和视觉，不涉及模型接口、文件写入或权限系统变更。
