# 项目导航、界面动效与中文化验证记录

日期：2026-08-17

## 本轮目标

- 在“置顶”和“最近”之间增加“项目”分组，按项目组织相关会话。
- 桌面端左栏保持固定展开，不再提供折叠入口及折叠动效。
- 个人菜单保留“使用情况”，但不显示剩余百分比。
- 右侧工具栏采用克制的抽屉动效；顶部双选切换采用滑动指示器。
- 自动化页面的用户可见名称统一为“技能 / 工作流”。

## 交互与视觉结果

1. 左栏新增三个项目示例，每次展开一个项目；项目内显示相关会话。
2. 左栏桌面折叠状态、按钮和相关样式已全部移除，移动端仍通过菜单按钮打开导航抽屉。
3. 右栏以 `220ms` 位移动效进入和退出，并保留透明度过渡；系统启用减少动态效果时自动缩短动效。
4. “聊天 / 工作”和“技能 / 工作流”共用滑动指示器，状态切换为 `220ms`。
5. 自动化页签、创建按钮、搜索提示、工作流标题、详情说明和右栏工具名称均已中文化。

## 验证结果

- TypeScript 类型检查：通过。
- 生产构建：通过。
- 桌面端：项目分组顺序正确，技能与工作流可切换，右栏可收起和恢复，无横向溢出。
- 移动端 `390 × 844`：页签完整显示，工作流卡片单列排列，无横向溢出。
- 个人菜单：显示“使用情况”，不存在“剩余百分比”。
- 浏览器警告与错误：未发现新增问题。

## 安全与代码审查

- 本轮只修改前端展示、导航状态和动效，不新增依赖、网络请求、文件写入或权限入口。
- ChangeSet 人工确认、公共知识发布确认、技能发布前代码与数据审查边界未改变。
- 对用户可见的中文名称与内部 TypeScript 类型名分离；内部 `SkillItem` 等类型名保持不变，避免无关重构。
