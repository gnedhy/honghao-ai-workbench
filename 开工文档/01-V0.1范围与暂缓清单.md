# V0.1 范围与暂缓清单

## 1. 产品定位

V0.1 不是完整的企业级中台，而是一套可在 Windows 本地独立运行的个人验证版。它需要证明：知识、智能体、Skill、Workflow 和人工审批能够围绕一个真实业务任务形成闭环，并且全过程可回看、可暂停、可恢复、可审查。

首个真实场景：**AI 需求诊断与项目运营**。

默认首屏：**个人 AI 会话**。用户可在同一会话中切换“聊天 / 工作”；需要持续执行、暂停恢复、调用工具或人工审批时，由工作模式创建任务。原智能体任务工作台下沉为“任务看板”中的任务详情和运行检查界面。

## 2. 本期必须完成

| 模块 | V0.1 范围 | 完成标准 |
|---|---|---|
| 个人知识库 | 1 个个人空间；Markdown 正文；AI 提议沉淀；可导出 | 可创建、检索、确认和导出；正文不被数据库锁死 |
| 公共知识库 | 1 个公共空间；候选进入审核 | 未经确认不得发布；可追溯来源和版本 |
| 个人 AI 会话与任务 | 会话提供聊天/工作模式；任务承载计划、事件、工具、暂停恢复和 ChangeSet | 用户可从会话发起复杂工作、查看任务进度、审批后回到原会话 |
| Skill 库 | `需求诊断`、`项目状态更新` 两个版本化 Skill | 能被任务明确选择、记录版本、产出结构化结果 |
| Workflow | 1 条固定 Workflow | 支持正常、补充信息、拒绝变更、失败恢复四类路径 |
| 模型接口 | 1 个 OpenAI 兼容 Provider；同时保留 Mock Provider | 不改业务逻辑即可切换；密钥不进入仓库和日志 |
| 工作目录 | 1 个受控目录 | 越界读写被拒绝并留下最小审计记录 |
| 安全与审查 | 数据出站检查、最小脱敏日志、个人代码复核清单 | 核心边界有验证样本；高风险动作默认阻断 |

## 3. 明确暂缓

- 多用户、组织架构、部门权限界面和统一身份认证。
- 可视化 Workflow 编辑器和拖拽编排。
- 多模型自动路由、模型市场、复杂计费中心。
- PostgreSQL、pgvector、容器化、集群和高可用。
- 任意 Shell、全电脑控制、生产系统自动回写。
- 现有企业知识平台迁移和海量历史文档导入。
- 自动把全部聊天记录沉淀为知识。
- 面向全员的 Skill 商店和复杂发布审批链。

这些能力只在 V0.1 的接口和数据结构中保留合理扩展边界，不提前实现。

## 4. 权限和责任边界

### 个人阶段

- 产品、模型出站判断、代码复核：项目负责人本人。
- 个人知识：本人确认后沉淀。
- 公共知识候选：即使只有一人，也必须执行一次显式“发布确认”。
- 代码合入：完成功能验证、安全检查、差异复核后才提交。

### 团队试用前新增

- 至少 1 名内部第二复核人。
- 明确公共知识管理员和敏感数据负责人。
- 复核日志、账号权限、备份恢复和异常处置流程。

## 5. 安全基线

- 只使用低敏或已脱敏样本；原始敏感数据不得默认送往模型。
- 模型请求前展示将要出站的上下文摘要，支持人工取消。
- 日志默认只记录时间、任务、步骤、状态、模型、用量和错误类别，不记录完整提示词、文档正文、密钥。
- 工具采用白名单和参数校验；所有写操作先产生预览或 ChangeSet。
- 密钥仅从本机环境或受控密钥存储读取，不写入配置文件、数据库、日志和版本库。
- 依赖、代码、数据结构变更都纳入复核；发现越权或泄露风险时阻断运行。

## 6. V0.1 总体验收

以下条件同时成立才算完成：

1. 可用一份真实但脱敏的需求材料启动任务。
2. 智能体能引用个人/公共知识并记录引用来源。
3. 需求诊断 Skill 能输出结构化诊断卡。
4. Workflow 遇到信息不足会暂停等待，而不是编造结论。
5. 所有正式写入先生成 ChangeSet，拒绝后不污染知识或项目状态。
6. 中断进程后可从检查点恢复，不重复已确认步骤。
7. 能导出个人 Markdown，数据库删除索引后可从 Markdown 重建检索。
8. 越界文件访问、密钥泄露和高风险出站样本均被阻断。
9. 关键代码通过自测、差异复核和安全清单。
