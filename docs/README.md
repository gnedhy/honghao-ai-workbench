## 目录用途

`business/` 保存业务说明与功能演进记录；`releases/` 保存发布、迁移及恢复证据；`changelog/` 保存按日期整理的更新摘要；`history/records/` 保存阶段验证与收尾记录。原有 `agents/`、`adr/`、`security/` 和历史资料目录继续使用。

带日期的文件保留当次事实，目录分类不代表全部内容仍是现行规则。当前状态从交接进入；历史端口、数据量和一次性授权不自动延续。新增文件按用途归类，日常入口更新本页，不在 docs 根目录堆积新的日期记录。
