# PostgreSQL 原生存储与隔离迁移

2026-09-14 用户决定在正式投入日常使用前迁移到 PostgreSQL，2026-09-15 授权开始后端适配。新版本使用原生 psycopg 和显式版本化 SQL；不长期维护 SQLite 双后端，不加入 ORM、运行时 SQL 翻译、额外工作进程或分布式服务。本记录替代 ADR-0005 中关于 SQLite 与模块启动自动升级结构的部分，保留其工作台边界和回退原则。

保留金额文本及 Python Decimal、JSON 与时间的原始表示、二进制密码材料及既有业务主键。增加显式排序列承接 SQLite 的插入顺序；写事务初期统一串行化，权限复查和写入共用连接，只读事务使用一致快照。服务启动仅检查结构，不以应用账号执行迁移；模块关闭时仍保留完整结构与数据。

先在独立分支、数据库与附件目录完成适配、全量迁入和恢复验收，经用户确认才切换正式服务。旧版和 SQLite 快照只用于离线迁移与恢复；新库已有正式写入后不能直接回退到过期 SQLite。数据库连接账号与业务人员账号分别管理，任何凭据和业务数据均不提交仓库。
