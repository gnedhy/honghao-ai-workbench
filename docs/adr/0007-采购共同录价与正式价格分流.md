# 采购共同录价与正式价格分流

2026-09-09 按已批准的真实数据接入方案，以共同本轮更新替代个人草稿或原料负责权限：采购编辑人员可维护全部目录价格，保存与正式启用分离，每次保存直接关联逐项变化。管理员及按账号标识配置的授权管理人员可授权启用；普通获授权者不得转授权。此决策替代 ADR-0006 的采购单人启用例外，不改变其他模块权限。

原料台账是唯一录价总表；数据分流独立管理六部门多对多清单，只读取当前正式快照。正式价格历史比较前一正式版本；操作记录只按实际工作批次关联，不用同日期推断。首次 Excel 迁入保留原文、单元格、原表采购员和真实来源日期，迁入执行人不能冒充过去的启用人。

首轮只进行隔离环境验收，不提交或推送。后续验收与提交授权以 ADR-0008 为准；正式环境的 GitHub Issue / PR、业务、代码、安全及回退门槛保留，不新增本地验收绕过路径。
