# DeepSeek Harness 作为可替换的智能体运行基座

宏昊 AI 采用 DeepSeek Harness 作为智能体执行器的首选运行内核，但不采用其 Web UI，也不让产品层直接依赖其内部事件、远程接口或持久化结构。

宏昊 AI 的会话、轻项目、任务、任务运行、知识库、技能、工作流、待确认修改及安全审查仍由产品层定义并持久化。产品层只通过稳定的 Harness 运行接口提交一次任务运行、接收标准化事件和请求取消；DeepSeek Harness Adapter 负责把这些操作映射到具体的 Agent、Session、工具和执行循环。

任务运行事件是宏昊 AI 的业务事实，DeepSeek Harness SessionEvent 是生成这些事实的执行证据。内核不可绕过受控工作目录、工具白名单、预算、网络出口、安全预检和人工确认边界，也不得直接写入项目卡或知识库。

由于 DeepSeek Harness 仍处于开发预览期，集成必须锁定精确版本或提交，并与确定性的 Mock Adapter 共享同一接口和验收。若内核不可用或升级失败，宏昊 AI 的业务数据必须保持可读取、可审计，且可以替换 Adapter 而不修改前端和产品领域模型。
