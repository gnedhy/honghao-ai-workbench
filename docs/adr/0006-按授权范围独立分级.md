# 权限按授权范围独立分级

系统不再给普通账号设置一个覆盖所有业务区域的全局等级，而是为每个授权范围分别保存查看、编辑或管理权限。这样一个账号可以管理采购工作台、只查看研发工作台，并在未授权销售工作台时完全不可见，避免跨范围过度授权。

业务权限逐级累积：查看只能读取授权数据；编辑可新建、修改、导入和提交，但不能使结果正式生效；管理可审核、退回、确认、发布及管理范围内业务。系统管理员独立设置，自动拥有全部范围以及账号、权限、模块配置、敏感字段和审计能力。部门和岗位仍然只是人员资料，不参与运行时权限判断。

敏感字段继续使用“开放范围 + 最低权限”判断；查看最低权限可为查看、编辑或管理，编辑最低权限只能为编辑或管理。旧角色表与 `identity_users.access_level` 列仅为数据库回退兼容保留，不再作为普通业务权限来源。任何审核或发布接口仍必须额外禁止提交人审核自己的内容。

当前只为工作台和知识库定义授权范围。聊天、自动化和任务看板在各自授权范围及数据隔离规则完成前，仅系统管理员可以访问；不得用“所有登录账号可用”代替正式授权。

## 采购单人流程例外（2026-09-05）

此节的单采购员启用规则于 2026-09-09 被 ADR-0007 替代；其他模块规则保持有效。

采购工作台按已确认的单采购员需求，允许采购编辑权限完成录入、补价、确认波动及即时或定时启用，不要求另一账号复核。上文禁止自审和管理级发布规则继续适用于其他模块。采购价格写入、波动确认及启用同时检查敏感字段写权限，不能仅凭采购编辑权限绕过字段限制。

正式价属于不可变基线；每轮候选价格归属于该工作批次，其他排期或已取消草稿不得参与即时基线组装。价格波动统一相对当前正式价计算，首次启用前才参考上期询价。候选价或正式基准变化后须重新确认；定时启用保留批准人与系统执行记录。
