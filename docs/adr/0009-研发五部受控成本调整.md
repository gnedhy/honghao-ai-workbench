# 研发五部受控成本调整

2026-09-14，用户批准在隔离预览实现研发五部账号及受原因约束的手动成本。当时约定预览验收后更新正式；同日已获用户确认并完成部署，见正式发布记录。

研发查看、编辑、核对启用仍分别使用现有范围等级。林菲菲配置研发管理（4），蔡诗璐、成运洪、卢彬、温豪配置研发编辑（3）。五人均可编辑研发五部全部产品，部门和负责人不授予权限。研发管理允许启用本人修改，此项明确替代 ADR-0006 在研发模块的禁止自审规则；其他模块规则不变。

编辑前必须记录调整原因，其他原因须填说明；试算、草稿和启用均由后端校验。两种成本口径分别选择自动核算或手动指定，手动值允许零且保留计算精度。投料、收率、原因或手动值变化，以及采购价格变化，均使旧试算确认失效。

采购仍只向研发传递价格，研发不反向更改采购台账。自动对照成本按当前有效配方递归核算，引用产品采用对应口径的最终成本。当前产品自己的手动值不作为自身自动对照值；手动策略启用后持续生效，采购更新只更新自动对照。恢复自动须重新记录原因并试算、保存、启用。

缺价保留自动核算异常，对应口径存在有效手动值时可采用该值；手动成本不豁免循环引用、无效投料或总投料等结构校验。历史冻结两种成本的自动值、手动值、最终值、来源，以及原因、编辑人和启用人。

旧配方和历史默认自动；旧草稿再次提交须补原因。不重导 Excel。账号配置通过显式脚本执行，先核对同名人员和登录名冲突，复用已有账号与密码；新账号沿用系统初始密码机制，脚本不自动随服务启动执行。

## 研发启用授权补充

复用采购的独立启用授权流程，使用独立的 `research_activation_grants` 与 `research_admin_events` 表。研发管理权限自带启用权；研发编辑获得独立授权后也可启用本人或他人草稿，不能据此停用配方或转授权。有效账号和研发编辑权限是独立授权的前提，部门、负责人不参与授权。

仅系统管理员可配置授权管理人员。林菲菲已在正式服务配置为研发授权管理人员，可授予或撤销普通编辑的启用权；其余四人初始无独立授权。撤销独立授权不移除管理权限自带的启用能力。授权及启用在写事务中重新读取账号和授权，防止撤权、停用、降级与启用竞态。

设置、我的权限、用户管理以及草稿启用提示采用实际能力。研发与采购授权互不影响；此前的原因、试算时效、保存锁定、历史冻结和手动成本规则继续有效。正式授权仍待预览确认后配置。

授权交互统一约定：采购、研发及后续授权均不得在勾选时立即写入。先展示对象、范围与变更内容，明确点击“确认授权”或“取消授权”后生效；“放弃操作”恢复原状态。授权管理身份变更遵循相同确认流程。现有两工作台复用同一授权组件及确认弹窗。
