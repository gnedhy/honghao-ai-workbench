## 运行

在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts/procurement_news_probe.py --browser --output C:/Users/gnedhy/AppData/Local/HonghaoAI/news-probe-20260910
.venv\Scripts\python.exe -m pytest tests/test_news_probe.py
```

输出目录包含 `index.html`（可直接打开）、`result.json`（来源状态）、`news-cache.json`（缓存）和 `runs.jsonl`（逐次运行记录）。重复运行更新缓存，单个来源失败保留该来源上次成功内容。不要把输出目录指向正式数据目录。`--browser` 需要 npx 和 Playwright CLI 可用；每次使用独立浏览器会话并在结束时关闭，不加载工作台账号。
