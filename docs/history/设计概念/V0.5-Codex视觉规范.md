# V0.5 Codex 视觉规范

## 设计结论

产品直接参考 Codex 桌面端的配色、排版、按钮、侧栏、分段标签、输入区和个人资料菜单，不再建立额外的“石墨仪器台”视觉方向。

视觉基准：[Codex 视觉基准 V0.5](<../README.md>)

V0.2 的信息架构和页面布局继续有效。V0.5 只决定视觉实现方式。

## 基础颜色

以下颜色是根据参考截图整理的近似实现值，不代表 Codex 官方设计令牌：

| 用途 | 建议值 | 说明 |
| --- | --- | --- |
| 主画布 | `#FFFFFF` | 聊天、工作和内容区域 |
| 侧栏 | `#EEF3F7` | 浅灰蓝，不使用深色侧栏 |
| 侧栏选中 | `#E2E8EC` | 柔和灰蓝选中块 |
| 主文字 | `#2F3033` | 避免纯黑造成过强对比 |
| 次级文字 | `#6E747B` | 时间、说明、引用数量 |
| 禁用文字 | `#A7ADB3` | 不可用状态 |
| 轻边界 | `#E4E7EA` | 只用于必要分组 |
| 浅表面 | `#F6F7F8` | 消息、分段标签底和局部悬停 |
| 主按钮 | `#25272A` | 近黑色，不使用亮蓝按钮 |
| 主按钮文字 | `#FFFFFF` | 白色文字或图标 |
| 活动蓝 | `#1683FF` | 只用于少量活动图标、链接或运行中状态 |
| 完成绿 | `#199A5A` | 已完成状态 |
| 等待橙 | `#E89A20` | 等待确认和提醒 |
| 危险红 | `#D92D20` | 删除、退出或真实危险动作 |

## 侧栏

- 固定浅灰蓝背景，与白色主画布形成低对比区隔；
- 一级菜单使用 16px 左右图标和紧凑文字；
- 当前项目或会话使用浅灰蓝圆角选中块，不使用亮色竖线；
- 分组标题使用更浅的次级文字；
- 个人资料固定在底部，设置只存在于个人资料弹出菜单；
- 弹出菜单采用白色背景、细边界、轻阴影和 10px 至 12px 圆角。

## 分段标签

- `聊天 / 工作`、`个人知识 / 公共知识` 等标签使用浅灰底分段容器；
- 选中项为白色，带极轻阴影；
- 标签文字保持深灰，不使用蓝色填充；
- 高度建议 34px 至 36px，整体圆角 18px，内部选中块圆角 16px。

## 按钮

### 主按钮

- 用于“交给智能体执行”“批准并应用”等唯一主操作；
- 近黑色背景、白色文字，圆角 8px 至 10px；
- 高度 38px 至 42px，左右内边距 14px 至 18px；
- 悬停时略微变亮，按下时降低亮度并缩小到 98%；
- 禁止使用蓝色渐变、强阴影和超大胶囊。

### 次按钮

- 白色背景、深灰文字、浅灰边界；
- 与主按钮保持相同高度和圆角；
- 用于拒绝、取消、返回等次要操作。

### 图标按钮

- 常规图标按钮使用透明或浅表面背景；
- 发送、语音或立即运行等强调动作可以使用黑色圆形按钮；
- 图标统一使用细线风格，禁止混用多个图标体系。

### 危险按钮

- 只有删除、退出或不可逆操作使用红色；
- 危险操作仍需二次确认，不依赖颜色表达全部风险。

## 内容表面

- 默认内容直接放在白色画布上，不为每个模块增加卡片；
- 用户消息可以使用浅灰圆角气泡；
- ChangeSet 使用轻边框、浅灰容器和浅绿色差异行；
- 底部输入区使用白色圆角容器、轻边界和柔和阴影；
- 圆角控制在 8px 至 14px，仅分段标签和圆形图标按钮使用更大圆角。

## 状态与反馈

- 当前运行使用少量蓝色，不把整个区域染蓝；
- 已完成使用绿色图标，并配合文字说明；
- 等待确认使用橙色图标，并保留明确的“等待确认”文字；
- 错误使用红色图标、错误标题和可恢复操作；
- 键盘焦点必须可见，建议使用 2px 低饱和蓝灰焦点环；
- 动效仅用于标签切换、按钮按下、消息出现和任务状态更新。

## 页面适用范围

同一套规则应用于：

- 新聊天的聊天模式和工作模式；
- 知识的个人知识和公共知识；
- 自动化的 Skills 和 Workflows；
- 任务看板的任务管理和运行记录；
- 个人资料菜单和系统设置。
