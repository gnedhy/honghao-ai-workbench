# 智能体任务工作台 V0.1 概念生成说明

## 生成方式

- 模式：内置 Image Gen。
- 类型：`ui-mockup`。
- 用途：企业 AI 中台 V0.1 的完整主屏设计规范候选。
- 图片：[智能体任务工作台-V0.1-概念稿.png](<../README.md>)

## 最终提示词

设计一个 Windows 本地运行的“企业 AI 中台”完整主屏，界面为真实内部生产力工具，不是营销页。使用 16:10 桌面应用截图完整呈现以下闭环：

`需求材料 → 知识上下文 → 智能体计划与执行 Loop → Skill / Workflow → 结构化诊断 → 人工审批 ChangeSet`

必须包含：

- 左侧主导航：`任务`、`个人知识`、`公共知识`、`Skills`、`Workflows`、`运行记录`。
- 任务列表：选中“跨部门 AI 需求诊断”，另有两个带状态的近期任务和“新建任务”。
- 中央工作台：任务状态、暂停/结束操作、执行计划与事件时间线。
- 执行步骤：`材料与数据边界检查`、`检索个人与公共知识`、`调用需求诊断 Skill v1.0`、`生成需求诊断卡`、`等待 ChangeSet 确认`。
- 结构化输出：`已确认事实`、`初步判断`、`缺失信息与风险`、`建议下一步`。
- 底部输入区：补充信息、附件和发送。
- 右侧检查器：`上下文`、`运行`、`变更集`，展示知识来源、Skill 版本、Workflow 版本、工具白名单、Loop 检查点、模型用量/成本和 ChangeSet 差异。
- ChangeSet 必须有“拒绝”和“批准并应用”，人工审批应成为正式写入前不可绕过的视觉中心。

视觉方向：真白背景、炭黑文字、钴蓝主操作色、克制的绿色完成态和琥珀色等待态；细边框、清晰中文排版、小圆角、适中密度。优先使用轨道、行、时间线、文档和检查器，不使用卡片堆砌。

禁止：营销标语、数据大屏、无关图表、虚假指标、科幻光效、玻璃拟态、装饰渐变、深色主题、过度圆角卡片、人物插画、夸张品牌标识、眉题/徽章/胶囊装饰。不得裁掉重要区域，所有未来交互文本和控件都应由 React 代码实现。

## 设计确认点

进入代码前确认以下五项：

1. 四栏结构是否适合日常使用：主导航、任务列表、执行区、检查器。
2. 中央“执行计划 + 诊断卡”是否是正确的信息重心。
3. ChangeSet 审批是否足够醒目且不会误触。
4. 颜色、密度和企业软件气质是否符合预期。
5. 是否将这张图锁定为 V0.1 前端实现规范。
