# 知识库字阶、新会话与右栏下拉验证记录

日期：2026-08-17

## 本轮目标

在不改变企业 AI 工作台产品主线的前提下，继续按 Codex 的克制视觉逻辑精修信息架构和交互状态：统一知识库命名与字阶，分开“新会话”和“已有对话”，并将右侧设置改成更直观的勾选式下拉浮层。

## 已完成

1. 左栏“知识”改为“知识库”，知识页顶部页签采用“个人库 / 公共库”，内部数据仍保留“个人知识 / 公共知识”的完整范围语义。
2. 统一字阶：一级导航为 14px；对话列表、个人菜单和常用页签为 13.5px；辅助信息为 10.5–12px。
3. 点击“新聊天”默认进入“工作”空状态，不再混入正在执行的示例任务；切换到“聊天”时显示独立的 Codex 风格空状态。
4. 置顶、项目子项和最近条目进入已有对话；“跨部门 AI 需求诊断”继续承载完整运行步骤、诊断卡、ChangeSet 与人工审批示例。
5. 右栏“知识范围”和“执行模型”由原生下拉改成轻量浮层，当前选项带勾选标记；右侧栏保留展开与收起动画。
6. 修复移动端任务表格引起的页面级横向溢出：表格仍可在自己的容器内横向滚动，页面本身不横向漂移。
7. 系统设置中的默认会话模式同步改为“工作”。
