# 工作模式项目上下文控件验证记录

## 本轮目标

在工作输入区的 `+` 旁补充项目上下文控件，并实现已选择、悬停移除和待选择三个状态。

## 已完成

- 工作模式默认绑定当前项目“宏昊 AI 中台”。
- 已选择状态复用左侧“宏昊 AI 中台”的蓝灰文件夹图标和项目名称。
- 鼠标悬停或键盘聚焦时，项目图标切换为灰色移除按钮。
- 点击已选择项目后，原位置切换为“选择项目”按钮。
- 未选择状态使用文件夹图标，不使用公文包图标。
- 点击“选择项目”后，原型重新绑定当前项目“宏昊 AI 中台”。
- 项目控件仅出现在工作模式，聊天模式保持原有输入结构。
- 整个项目标签均可点击，触屏设备不依赖悬停也能移除项目。

## 验证结果

- `npm.cmd run typecheck`：通过。
- `npm.cmd run build`：通过。
- 默认状态：项目名称正确，控件宽约 106px。
- 悬停状态：默认图标透明度为 0，移除图标透明度为 1。
- 待选择状态：“选择项目”按钮宽 85px，已选择项目数量为 0。
- 聊天模式：项目控件数量为 0。
- 390px 宽度：工作输入框宽 362px，两种项目状态均无横向溢出。
- 浏览器控制台：无错误和警告。
