# 侧栏职责、品牌与视觉精修验证记录

## 本轮目标

- 产品界面品牌由“企业 AI”调整为“宏昊 AI”。
- 左侧栏支持桌面端收起，移动端仍以完整抽屉呈现。
- 右侧栏承接当前页面的设置、属性和操作，不与主内容重复。
- 视觉保持 Codex 式冷静中性色、低对比边界、单一图标体系与克制动效。

## 区域职责

| 区域 | 核心职责 | 不再承担 |
| --- | --- | --- |
| 左侧栏 | 全局模块导航、置顶会话、最近会话、个人入口 | 当前任务的执行设置和对象属性 |
| 主内容区 | 会话内容、文档正文、Skill 定义、任务列表与审批内容 | 重复出现的模型、知识范围和页面级操作 |
| 右侧工具栏 | 当前会话设置、文档操作与属性、Skill 版本操作、任务详情与控制 | 装饰性摘要和主内容复述 |
| 顶部栏 | 当前对象身份、聊天/工作等模式切换、右侧工具栏开关 | 大量业务按钮和重复导航 |

## 已实现交互

- 左侧栏在桌面端可在 292px 与 72px 两种状态间切换，收起后保留模块图标和个人头像。
- 手机端忽略桌面收起状态，导航抽屉始终显示完整品牌、栏目名称和会话列表。
- 会话右栏可切换知识范围与模型、暂停或继续任务、进入任务看板。
- 知识右栏随当前文档切换，提供导出和公共知识候选操作反馈。
- 自动化右栏随当前 Skill 切换，提供测试、创建版本和发布检查。
- 任务右栏随当前任务切换，提供运行信息、暂停/恢复和返回来源会话。
- 手机端左导航与右工具抽屉互斥，不会同时覆盖主内容。

## 视觉精修判断

- 设计变化度 4/10：延续既有信息架构，只调整职责、层级、间距和状态。
- 动效强度 3/10：只保留收起、抽屉、悬停和按压反馈，并支持减少动态效果。
- 信息密度 6/10：主工作区维持专业工具密度，右栏采用开放分组与细分隔线，避免卡片堆叠。
- 未增加渐变、发光、装饰插画或多套圆角；按钮保持深色主操作、白底次操作和图标轻操作三级关系。

## 安全与代码审查边界

- 本轮未增加依赖、网络请求、模型密钥、文件写入或持久化能力。
- 所有高影响操作仍为前端原型反馈，不会直接写入本地文件、项目卡或公共知识。
- ChangeSet 人工确认、公共知识独立发布确认、Skill 发布前代码与数据审查继续保留。
