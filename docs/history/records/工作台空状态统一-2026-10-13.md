# 工作台空状态统一

本轮按用户要求统一其它页面的空状态，参考任务面板灰色线条图标与简短文案；完整门禁留到收工前。后续截图反馈确认两点：会话管理空提示必须在整个列表区居中，侧栏会话提示保持纯文字。

## 实现范围

- `WorkbenchLayout.EmptyState` 复用 `PageState` 语义与现有 CSS 模块，无新依赖。正文48px图标，菜单／项目详情20px紧凑图标；无背景及状态色，opacity .4。列表内容区、空指令阅读区、反馈内容区与管理员空详情采用可用区域内居中。
- 任务五列／列表／运行、会话管理与空内容预览、个人记忆与未设置指令、反馈、管理员审计／授权／部门与人员、采购台账／价格历史／资讯、研发原料／产品／配方／成本历史及看板、销售目录／报价／热门产品／价格历史／测算历史与候选菜单同步适配。
- 删除重复“暂无”和无意义解释；一期成本／报价真实数值、不可比较原因及记忆整理条件保留。零原料集合显示“暂无原料”，不建议清除不存在的筛选。反馈读取失败不会同时显示“暂无反馈”。
- Sidebar 的无项目／无会话／无关联会话仍为纯文字。知识／自动化既有组件仅同步空展示，不启用这些模块。
- 请求、权限、持久数据、记忆生成、指令选择及任务执行不变。采购图表失败沿用独立错误分支，不用空集合图标表示失败。
