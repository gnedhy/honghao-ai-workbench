| [researchEditSession](../../../src/workbenches/researchEditSession.ts) | 当前填写、可编辑字段基线、草稿序号、试算凭证、保存锁、启用确认、取消保存和冲突核对，包含取消与卸载清理 |
| [ResearchFormulaEditor](../../../src/workbenches/ResearchFormulaEditor.tsx) | 原编辑界面、差异核对和局部拖拽；会话按产品 ID 挂载，后台详情刷新不重新初始化填写 |
| [researchData](../../../src/workbenches/researchData.ts) | 根产品／历史／配方三项合并读取，10 秒定时和聚焦单飞，手动／写后读取取消旧请求；进入原料页或卸载时取消根读取 |

| 状态 | 创建、转换与保护 |
| --- | --- |
| 本地输入／dirty | 从已保存草稿或正式配方规范化初始化；调整原因、负责人、收率、双手动成本、联动和逐项投料均参与指纹。服务端编辑人等元数据不形成假 dirty；原因弹窗尚未进入编辑器的修改也受退出保护 |
| 试算及凭证 | 明确试算后启动原 350ms 输入更新；新输入取消旧请求。结果对应当前填写与 draft revision，旧回包不能提供可保存凭证；取消试算清理结果。后端 token／价格／配方校验保留 |
| 保存草稿 | 同步互斥，成功更新 revision、token 和基线，锁定填写；失败保留输入。保存不改变正式成本；卸载后不调用旧宿主刷新／返回 |
| 已存草稿重开 | 原冻结试算先展示，后台重新核验期间禁启用；失败保留草稿并提供明确试算重试，不必先删除草稿 |
| 本地返回／取消保存 | 放弃本地输入不删除服务端草稿；明确取消保存才删除当前 revision 草稿，仍保留本页填写并收起试算 |
| 冲突核对 | 读取最新版本但不替换本地填写；明确核对后采用最新服务端输入基线，清理旧试算／确认。保留输入不同于当前服务器时仍为 dirty；再试算后才能保存／启用 |
| 启用确认／忙碌 | 保存、取消保存、启用、核对互斥，填写、关闭和共享退出受保护；标题删除和停用期间编辑入口也使用同一忙碌边界。后端事务权限和版本验证继续生效 |

最新优先、库存优先、每层收率、手动零值及 Decimal 舍入口径沿用后端。正式记录、引用链、版本展示和走势图刻度沿用原实现。原料页仍从 W6 公共 `ProcurementMaterialView` 注入研发自己的只读 GET；导出仍为原 `/products/export`，只增加卸载取消与晚回包不下载，没有改变工作簿内容或权限。
