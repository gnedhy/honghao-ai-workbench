## 产品与数据

项目详情提供实际名称、会话和冻结归属任务；输入区移除未接通的附件、知识、计划、技能、工作流及模型切换。消息接受后幂等启动，启动失败保留接受记录；聊天无任务，工作补充沿用任务。任务看板和详情显示实际运行、时间、正文、停止状态及已报告用量。没有新职能工作台或运行时注册。

列表、消息、草稿及运行请求归所属业务 Hook。共享 dirty／busy 检查覆盖对象、模式、项目关联和页面出口；运行期间允许编辑下一草稿，离开不取消后台。未知创建／接受响应按原稳定键确认，更名冲突保留提议；过期读取按对象取消、版本合并。任务列表／历史 403 只使任务能力失效，不能清除仍可用聊天；迟到工作回执也不启动执行。身份失效立即清理，失效回调只触发一次，仅清理并重新读取身份，不自动注销新 cookie 的账号。可选 X-Workspace-Actor 比对已认证身份，不授予权限；跨标签换账号的旧草稿提交已实际复现、修复并验证。无主历史管理员只读，输入和项目修改均禁用。

0008 为项目增加可选创建 UUID 与原始名称，core schema8，其他领域版本不变；title-only 调用继续兼容。创建请求在项目改名后仍去重；冻结 SQLite 投影明确排除新元数据。快照摘要将原生 UUID 转为规范字符串，保留原 bytes 序列化；实际 PG 快照恢复后仍可重放创建回执，原项目、名称、所有者、任务及运行记录不变。

## 定向与视觉验证

类型检查、React／依赖边界检查通过，69 Node 用例无 skip。新增两个 API 检查验证并发创建／更名后回执及所有者隔离、较早活动输入对账与安全运行 DTO。新增真实 App＋API＋隔离 PG wrapper 覆盖五个场景：

- `h05-project-receipt-rename-and-exits`：断线创建结果去重、保存期间后续编辑、更名版本冲突与取消关闭。
- `h05-chat-work-draft-and-real-history`：发送期间下一草稿保留、聊天无任务、工作连续任务、实际运行详情。
- `h05-mobile-navigation-draft-preservation`：手机出口取消、任务 403 后聊天草稿保留；延迟接受回包失效后执行 POST 为零，服务器接受记录保留且没有运行。
- `h05-legacy-admin-readonly-consumer`：管理员查看无主历史任务和会话，输入、提交与项目修改禁用。
- `h05-identity-switch-never-submits-old-draft`：同浏览器 cookie 切换账号后旧页面不能把草稿创建为新账号记录，重新读取当前身份且不注销新账号。

H03／H04 原有实际消费者继续执行；原场景名称和覆盖保留，测试入口适配 H05 自动启动及原生菜单。H03 关联冲突验证同时覆盖取消保留初始草稿和保存期间后续输入；H04 明确预置待执行输入，继续覆盖先后顺序、配置重试、旧回包、断线、停止和撤权。模型、原生 stdio 与 OS 边界在这些 fixture 中为明确模拟，不代替 Ubuntu 实测。
