## 原问题与修复

前三项确认问题先与文件提取分开处理；第四项在验收中补查并修复。后端冻结和权限保护有效；下面问题不代表正式历史曾被覆盖。

| 可达问题 | 根因和处理 | 回归 |
| --- | --- | --- |
| 部分采用后续报，或采用后添加产品，保存被拒绝 | 草稿序列化把自动采用项的最终价清为 `null`。合并优先保留未进入调整的已采用服务端项，发送原价格和全部输入字段 | `w4-partial-continue-save`；`w4-adopt-then-add-product` |
| 采用后仍能改冻结产品和客户类型／信息，保存失败 | 界面与操作缺少已采用边界。业务动作统一使用已有 `patchItems` 的可编辑规则，批量只改待处理或有调整原因的产品；原生禁用冻结输入和客户信息，调整继续从历史详情 `revise` 进入 | 同一编辑器锁定、批量保留单项利润／手填价／特殊公摊、部分采用边界 |
| 旧报价显示新目录价格，却仍按旧成本保存 | 原初始化用当前目录覆盖保存的产品快照。已有报价优先 `item.product`，目录仅服务新产品和采用前比较；不自动刷新成本 | `w4-reopen-saved-cost-snapshot`：真实目录 4→12，仍显示 6.92；改运费后显示／实存 7.05，明确保留成本 4 后采用 |
| 重开未测算草稿或进入调整时，只显示采用而无法保存 | 初始保存基线只检查 existing 存在，未检查测算完成。已有报价的可编辑项须具备结果、trial ID 和确认标记才初始化 clean；否则完成保存测算。新报价和冻结项保持原初始规则 | `w4-uncomputed-draft-reopen`；实际详情 revise 后不改输入，直接保存／确认低价／采用，再调整第三版 |

参数或手填价改变后的定价依据、低价确认仍由现有服务端规则要求。新场景第一次遗漏选择依据时，后端正确拒绝；修正测试操作后通过，没有降低校验。最初新增产品的定位器误匹配外层 `article`，随后限定实际报价 dialog；这些测试定位失败不算业务红证据。

## 状态归属与接口

| 对象 | 创建／保留 | 失效／清理 |
| --- | --- | --- |
| 客户、类型、产品和单项参数 | `useSalesQuoteSession` 每次挂载惰性初始化一次；唯一可写输入；目录刷新只更新目录 | 新编辑过程重挂载；关闭后释放。切类型按现有规则换默认参数 |
| 保存基线和对象版本 | 会话保留 `savedBatch`／指纹；dirty、待采用 ID、校验及提示直接派生 | 开始保存即使旧基线失效；只有草稿与测算完成才恢复可采用状态 |
| 三阶段请求回执 | 同步 `writing` 锁；原请求 `pendingWrite`、成功草稿指纹；失败保留输入，丢失响应先重放原请求 | 422 可修正输入再写；401／409 保留原请求与输入，不自动新建或覆盖；再次发送仍由服务端校验。成功清原请求；恢复上限为当前挂载，跨刷新卸载没有持久恢复 |
| 采用确认 | 仅保存干净且等级 4 可采用待处理项；执行前再次读取目录 | 保存／采用完成清理成本和低价确认；新输入须重新保存 |
| 批量未应用值和展开状态 | 展示组件的本地提议值，不是第二份报价输入；应用时交给会话动作 | 应用成功后清空；关闭卸载清理；空字段保留原单项值 |
| 退出 | 会话复用 `useUnsavedChanges`，展示复用 `Drawer` | 忙碌阻止离开，取消保留输入；卸载由已有公共保护清监听和待决确认 |

工作台公开入口仍为 `SalesWorkbench`，由 `ModuleSlot` 挂载。内部 [SalesQuoteEditor](../../../src/workbenches/SalesQuoteEditor.tsx)只组织既有客户区、卡片、批量、选择器、采用确认和页脚；[salesQuoteSession](../../../src/workbenches/salesQuoteSession.ts)拥有创建／草稿／测算／采用协调及领域动作，不向父级暴露 setter。[salesModel](../../../src/workbenches/salesModel.ts)复用已有公式与批量规则，承接原纯输入指纹、快照初始化、草稿合并及金额格式化。

编辑组件 key 取本次打开上下文中的原批次 ID 或 `new`，不随保存所得 ID／revision 改变；目录 `onChanged` 不改变上下文。关闭后条件渲染卸载，继续另一报价重新挂载。现有目录、批次、测算及记录的关联读取保留在工作台，详情动作保留原实现；没有为了拆文件建立重复请求 Hook，也没有兼容壳或重复可写副本。新增同类报价参数主要维护销售模型／会话／展示，不改 `App`。

唯一移动的目录读取 effect 改为完整 `savedBatch` 依赖，删除该 Hook 的一条历史基线；剩余 22 条保持原登记。未扩大例外、关闭规则或改公共样式。
