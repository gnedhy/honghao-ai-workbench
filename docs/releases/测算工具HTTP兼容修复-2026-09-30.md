# 测算工具 HTTP 兼容修复（2026-09-30）

进入销售“测算工具”时，面板初始化直接调用 `crypto.randomUUID()`。该接口在普通 HTTP 来源下不可用，导致整个工作台进入加载失败状态。隔离浏览器使用映射到本机的 HTTP 域名复现了同样的错误；本机回环地址可用，故此前仅检查本机地址时未发现问题。

前端统一通过 `src/clientId.ts` 的 `createClientId` 生成标准 UUID v4，使用在普通 HTTP 来源下也可用的 `crypto.getRandomValues`，保留安全随机数和原有编号格式。测算面板、计算步骤及消息提交复用该函数；消息失败重试仍沿用同一个提交编号。无依赖、接口、成本算法、数据库、人员权限或模块配置变更。系统更新日志已补记本次修复。
