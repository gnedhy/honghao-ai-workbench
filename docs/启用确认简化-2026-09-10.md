# 启用确认简化

> 2026-09-14 边界更新：未启用功能模块与总经办工作台统一锁定，不能通过确认步骤重新开启。下述确认机制仍用于可操作的工作台及有效运行模块，旧恢复案例仅供追溯。

当前配色：主按钮、权限勾选和启用开关统一采用黑色，`--primary: #25272a`，`--enabled-color` 引用同一值；悬停和按下采用深灰。保留布局、动效、键盘焦点可访问性与业务状态。最新构建核对见 [提交准备](./提交准备-2026-09-10.md)。

用户批准：不再手填 Issue/PR 地址，首次启用保留四项可理解的确认；已有有效记录的恢复启用只确认一次。系统自动保存实际确认人的身份、时间、勾选项及启用边界修订号，不伪造开发记录链接。旧的有效带链接记录兼容保留。

后端在模块和职能工作台两个入口校验。无记录或边界修订变化时必须四项齐全；不接受部分勾选。`api/modules.py` 的 `ACTIVATION_REVIEW_REVISION` 由发布维护人员在重大启用范围或安全边界变化时递增，不通过普通 UI 改版自动判定。历史记录有效性与是否可复用分离，避免版本变化导致当前运行配置失效。
