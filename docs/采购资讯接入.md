## 运行与依赖

项目锁定 `playwright@1.63.0`，部署准备时运行 `npm ci`，再运行 `node node_modules/playwright/cli.js install chromium` 安装对应浏览器。服务运行时仅调用已安装的 Node 与浏览器，不执行下载。Node需在服务进程PATH中；浏览器需安装到运行服务的用户环境。缺失时资讯更新延迟，采购功能仍可使用。

采购模块为active时，服务启动独立采集任务：无缓存或超过一小时立即采集，否则等待到期。每轮完成后间隔一小时，服务关闭不采集，下次启动补跑；锁避免同实例重叠。与价格启用任务独立，页面只读缓存，不触发外部采集。候选前端构建使用 `npm run build -- --outDir output/news-candidate/dist`，不覆盖正式dist。

三个固定适配器：商务部贸易救济列表（化工关键词过滤）、生意社化工列表、隆众热点列表。每个来源各自超时、重试一次，只接受可见的白名单文章链接及页面日期，不从URL猜日期。列表不保证历史全量或采集间隔中的所有新条目。此前 `procurement_news_probe.py` 的CLI仅保留作独立验证；运行服务使用 `procurement_news_browser.mjs`，不调用验证CLI。

## 缓存与接口

- 缓存：当前环境数据目录下 `procurement-news/cache.json`，临时文件原子替换；与价格表隔离，不读取/发送原料、价格、账号信息。
- 按原文URL合并，进一步按来源、标题、日期合并重复入口；保留最近30天，单源失败保留上次成功条目。损坏缓存安全回退。
- `GET /api/workbenches/procurement/news?source=all&page=1`，来源支持all/market/商务部/生意社/隆众资讯。沿用采购查看权限（2）。返回items,total,page,page_size,sources,updated_at,delayed。market仅生意社和隆众，一次返回已编排好的最多10条，由卡片本地分成两页各5条，翻页不请求外部来源；其余接口20条/页。
- 页面日期保持原精度；无时间不显示00:00。更新时刻为北京时间，与文章日期分开。最近30天从服务当前日期计算，不跟随价格版本日期。
- 来源每轮失败即延迟；两小时未成功也显示延迟。关闭时先通知浏览器退出，超时后Windows终止该采集进程树。
