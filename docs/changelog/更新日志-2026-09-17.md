# 2026-09-17 更新日志

销售报价候选版本；正式启用状态以现役配置和发布记录为准。详细规则见[销售报价工作台](../business/销售报价工作台-2026-09-17.md)。本次同时维护系统内“设置 → 关于系统 → 更新日志”。

- 销售报价测算：同页查阅正式产品成本并建立客户清单，支持国内直接厂、国内中间商、外贸直接厂和外贸中间商；两类外贸共用外贸公式。批量调整费用和系数后可逐项处理例外。
- 草稿与采用：保存本次询价草稿，按产品采用最终对外价；保留测算历史、客户及业务员，允许暂未编码客户报价与后续补录。
- 定价依据与调整：勾选定价依据，服务端冻结成本、参数和结果。已采用报价调整需要原因，再次采用形成新版本；作废保留历史，不恢复旧价。
- 数据与部署：新增 PostgreSQL 顺序迁移，复用销售权限和归属校验，保留现有正式数据边界。备份、恢复和冻结 SQLite 基线迁入兼容新增报价表。

## 2026-09-18：报价台账改为产品成本＋报价参考

- 首页统一为产品成本台账，列出产品内编、数据来源（版本与日期）、双成本及直接厂／中间商／外贸三项报价参考。
- 移除表格操作列，点击产品内编查看成本依据和报价参考；调整参数仍通过抽屉完成，历史快照与采用流程保持不变。
- 销售产品抽屉按研发成本抽屉的宽布局、双成本卡片、依据明细、历史展开和关闭过渡重新实现，销售数据与报价调整保持独立。
- 抽屉内容收敛为“成本依据、报价参考、价格历史”三个区块：成本来源、价格版本和日期并入成本依据；报价参考沿用研发抽屉的成本口径切换按钮；价格历史按报价版本、日期、状态和涨跌幅展示，展开后显示测算成本、三类报价结果、完整系数和定价依据。报价系数编辑仍在抽屉内按需展开，应用后才写入当前草稿；已采用产品仍需先填写调整原因。
- 报价参考补充“价格对比”视图：三个报价卡并列显示最新优先与库存优先结果，标出成本口径和两者价差；切回单一口径仍沿用当前报价成本选择。
