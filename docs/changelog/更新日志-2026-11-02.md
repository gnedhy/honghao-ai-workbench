# 2026-11-02 更新日志

## 原料报表导入

保留原有人工录价，新增文件导入更新方式。支持 Excel、CSV、TXT，识别采购员、库存数量、含税库存价格和行情价格；可下载 Excel 模板。

选择文件后自动检查，默认只读。点击“编辑数据”可以修正明细，完成编辑后再保存。统一导入对话框的字体、列宽、间距和对齐，简化来源文件及录价说明，修复打开导入窗口时台账闪动。

保存后继续按原有流程核对启用。启用时行情与库存共同生效，新增价格历史并联动产品双成本；取消未启用的批次不改变正式库存。报表采购员显示为修改人，实际操作账号保留审计记录。

## 升级说明

这是程序功能更新，不是整库数据替换。对已有 PostgreSQL 数据库执行增量迁移 19、20，保留现有账号、权限、配方、报价、人工修改、草稿和历史。不导入开发机备份或测试数据，不重复执行历史业务更正脚本。服务器步骤与兼容边界见[发布与升级说明](../releases/原料报表导入正式更新-2026-11-02.md#已有服务器只更新功能)。
