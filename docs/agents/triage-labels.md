# Triage Labels

| Skill 标准角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由智能体实现 |
| `ready-for-human` | `ready-for-human` | 必须由人工处理 |
| `wontfix` | `wontfix` | 不进入实施 |

当 Skill 提到某个标准角色时，使用本表对应的 GitHub 标签。
