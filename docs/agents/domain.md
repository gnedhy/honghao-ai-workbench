# Domain Docs

## 工作前读取

涉及业务规则、权限、成本逻辑或领域命名时：

1. 读取仓库根目录 `CONTEXT.md` 中相关概念及其边界；文案、样式等不涉及领域语义的修改无需全文读取。
2. 读取 `docs/adr/` 中与当前功能相关的决策记录。
3. 若文件尚不存在，继续工作，不需要提前创建空文档。
4. 新概念或重要决策经确认后更新领域文档；已确认决定的事实纠错可直接同步，不重启领域建模流程。

## 当前结构

本仓库采用单上下文结构：

```text
/
├── CONTEXT.md
├── docs/
│   ├── agents/
│   └── adr/
└── src/
```

## 语言约束

- Issue、规格、测试和代码中的领域概念应采用 `CONTEXT.md` 的正式名称。
- 不要为已经定义的概念随意创造同义词。
- 如果现有词语无法准确表达业务含义，应进入领域建模流程，而不是在代码里自行命名。

## 决策约束

如果拟议方案与已有 ADR 冲突，必须明确指出冲突，不得静默覆盖原决策。
