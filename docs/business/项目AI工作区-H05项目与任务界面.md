## 会话与项目

项目详情底部「移除项目」经一次确认，仅设本人项目 removed 标记并递增 revision；不删除／脱离会话、任务、运行、验收或冻结来源。日常项目入口和新关联选项隐藏，历史元数据保留，原会话可继续；新会话和新关联拒绝已移除项目。

- 全局新聊天默认聊天、无项目；项目内新建默认工作且明确关联项目；任务面板“创建任务”进入工作草稿，提交前不产生任务。只在新会话选模式，保存后隐藏模式切换。独立目标新建会话，同任务补充和延伸沿用明确 taskId。
- 项目名称、图标、颜色按本人所有权及 revision 保存。稳定创建键对账原始请求，创建回包未知或并发更名时保留提议，不按名称猜测对象、不覆盖较新版本。项目详情显示实际未归档会话和可读任务，关闭任务模块不能把不可读统计伪装为零。
- 会话有自动短标题、手动更名、置顶及归档。首次短标题复用一次有界命名请求，失败不阻止正文；任务名称沿用同一请求，不额外重复命名。手动更名冻结打开编辑器时的 revision；后台出现新版本时展示当前名称、保留提议，明确再次保存后才采用新版本。
- 侧栏独立置顶区位于项目上方；最近支持全部／聊天／工作筛选，项目下会话和项目名称同起点、同字号。模式按实际提交推导，与是否关联项目及任务读取权限分开。
- 会话三点菜单、直接图钉和项目／分组操作按悬停、键盘聚焦或触屏规则显示；复用已有菜单、图标和退出保护。

## 接受、执行与连续对话

- 提交先接受正文，再幂等启动该输入。未知接受回执沿用原提交键对账；未知启动回执先 GET 读取事实，不自动重新 POST。已终结运行不重放；失败重试新增明确一轮，保留旧失败和同任务来源。
- 正常发送期间隐藏旧待执行提示及操作。执行状态按 owner／会话／输入／revision 绑定；正常回复用紧凑处理记录，失败或受阻的最新输入用两侧细线和居中“重试”。停止表示请求已接受，终态由服务端确认，已生成正文和后续草稿保留。
- 健康线程使用固定 Codex 的历史及原生自动压缩；只有上下文失效或提交 turn 之前明确 resume 拒绝时，用本人同会话的有界产品历史恢复。中文正文使用 UTF-8，原生环境说明、私有推理及旧 DSML 不作为产品上下文重放。详见 [H04 合同](项目AI工作区-H04运行接入.md)。
- 工作显示真实 last.totalTokens／modelContextWindow 及自动整理状态；输入区使用悬停三行居中提示和 K 数字，只显示当前使用量／百分比／窗口总量；不显示剩余比例或阈值行。configured_auto_compact_tokens及历史context_usage事件继续保留，旧API兼容；整理开始时正文区复用重试分隔线，居中灰色文档图标与“正在精简上下文”，无按钮，完成后退出；聊天使用同样后台管理但不显示窗口和整理提示。累计模型收费用量独立；没有真实事件时不伪造压缩。
- Markdown／GFM 正文复用 MessageBody，表格和代码只在自身区域横滚；原始 HTML 与不安全链接不能执行，复制保留原始文本。文件和图片成果仍由 H06 接入。

## 任务面板与人工验收

“任务面板”沿用原 tasks 模块。Apache-2.0 的 dashi-taskboard 状态列、卡片及筛选适配来源见 third_party；使用本产品 API 和数据，不引入外部任务数据库或启动器。

| 分组 | 实际状态 | 操作 |
| --- | --- | --- |
| 待执行 | created | 开始已接受任务 |
| 处理中 | running | 查看进度、停止任务 |
| 待跟进 | waiting／failed／blocked／stopped | 查看原因、回来源会话继续处理 |
| 待验收 | review | 查看最新结果并验收、继续修改 |
| 已完成 | completed | 查看结果、延伸原任务 |

- TaskRun.completed 表示本轮运行成功；Task.review 表示结果等待本人验收。只有本人确认最新成功、已结束结果，任务才 completed。验收不得调用模型、改正文或新增运行；每轮 accepted_at／accepted_by 保留，延伸后重新待验收。
- 状态分组、列表、运行记录使用同一持久任务和运行；筛选项目／状态／文本，清除筛选后恢复。筛选计数在页头、清除在原工具栏；读取／筛选不额外插入行挤动内容区，运行选择区为空时保留高度。运行记录按轮次显示起止时间和真实验收凭据，不把运行成功显示为任务完成。
- 点击任务或运行展开原 320px 右栏，不另开任务详情抽屉。详情按侧栏字号、折叠信息和共享渐隐滚动设计；任务面板与详情共用一次运行读取。验收／开始／停止回执 busy 时，切任务、切运行、关闭、导航及归档其来源会话均走同一保护，包含单任务自动选择。
- 每列最多五卡高度，超出在列内滚动，低视口适配。空集合保留五列；空图标是独立灰色线条、无底色，opacity=0.4。列表和运行记录保留自身表头、空／错误状态与局部滚动。
- 保留任务冻结的项目来源；会话关联改变或项目更名不改写任务来源。旧无主记录仅管理员只读，不提供验收和执行。没有暂停、手工拖动状态或自动调度能力。

## 归档与设置内管理

- 系统设置的“会话管理”复用其他设置 TAB 的列表、字号和滚动样式；搜索归档记录、只读查看正文、恢复、一次确认后永久删除。没有回收站。
- 归档从侧栏、项目详情、全局搜索和日常任务集合移除，保留消息、任务、各轮运行及验收凭据。恢复返回原 ID 和历史。原始 API 的历史读取与日常入口分开。
- DELETE /api/conversations/{id} 使用 strict revision，仅本人归档且无活跃运行可删；204 成功，同事务移除产品数据库中的会话、消息、任务、事件和上下文绑定，项目及其它会话保留。未知删除回执按本人完整列表确认，不盲目重发 DELETE，迟到旧回包不能恢复已删记录。
- 永久删除指产品在线记录无法从正常恢复流程找回，不承诺擦除受保护备份或原生私有缓存。缓存／备份及 H06 文件的保留、清理和恢复规则应在相应生命周期合同明确；本轮不删除用户备份或原始验收证据。

## 身份、权限与退出

App 只协调身份、选中对象和导航；列表、提交、请求、权限和草稿由业务 Hook 维护。公共 Composer、Sidebar 和菜单只接收值与操作提议，公共类型来自共享入口。

JSON 工作区读取和运行操作携带所属登录身份的 X-Workspace-Actor；可选参数保持旧请求兼容。EventSource 使用 cookie 和服务端逐批资源鉴权。跨标签账号变化拒绝旧页面请求，清理旧身份正文、草稿及订阅，不自动注销另一个标签的新账号。

任务集合的 403／模块关闭 404 只撤销任务能力，聊天保留；单资源 404 不等同模块关闭，执行 Hook 向调用方保留真实 401／403／404。读取用请求代次丢弃旧回包，消息按 immutable ID、对象按较高 revision 合并。

所有可达出口沿用 useUnsavedChanges／confirmWorkbenchLeave。接受、保存、验收和停止回执 busy 时不能卸载对象；dirty 取消保留输入。服务器后台运行本身允许离开，页面卸载不隐式取消；身份失效不等待 dirty 确认。
