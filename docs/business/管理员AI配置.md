# 管理员 AI 配置

系统设置在「常规设置」之后增加仅系统管理员可见的「AI 配置」。模型接入、预算与用量、并发与排队分别保存；失败保留草稿，版本冲突可读取最新版本后核对原草稿再保存。

三个页面使用普通文字标签，不使用滑动选中效果。「个人例外额度」点击配置行进入独立配置页，可搜索姓名、账号或部门。勾选用户并填写额度，留空表示该用户不设额度；取消勾选恢复默认额度。返回上一级保留当前预算草稿，修改通过固定底部保存按钮生效。

主页面保留默认模型、公司预算、个人默认额度和执行名额；只有一个开放模型时默认模型显示文字，默认模型不再提供无效关闭开关。推理默认值和允许档位合并到「推理设置」；密钥输入、更换与连接测试合并到「管理接入」；价格快照、来源／版本及模型原生限制合并到「模型与计费详情」，单价默认只读，点击调整后可编辑，非自动同步官方价格。

预算占用为已核算预估费用与待核算预估合计；主页面保留余额、非零待核算提示、额度提醒和个人例外入口，费用／Token／人员／部门合并到「查看用量明细」，姓名附账号标识。并发主页面保留状态及当前策略摘要，三个排队参数进入「排队策略」；已有自定义值照实显示，不重置为推荐值。读取时间与刷新按钮位于状态区域，刷新保留草稿；时长截至读取时点，运行、排队、等待输入分别显示。等待以分钟编辑、整数秒保存；金额按原十进制字符串提交，所有详情返回后仍保留草稿和校验，后端权限、费用与版本检查继续有效。

模型、推理、上下文、压缩、个人／项目指令和记忆复用固定 Codex Harness 0.160.0。工作台只负责账号权限、受控 DeepSeek 代理、费用账本及公平调度；原生 agents.max_threads 是子 Agent 限额，不是企业运行名额。

## 配置与费用

- 默认 Flash／high；2026-10-14 用户确认暂时只开放 Flash：Pro 保持关闭，移除主页面的 Pro 开放开关，不新增模型配置下拉；模型与计费详情仅显示已开放的 Flash，Pro 的兼容验证与价格资料保留，后续开放另行确认。用户只能选已开放模型和推理档位；轮次创建时冻结模型、档位、价格和凭据版本。
- 真实密钥保存在服务器私有目录的版本文件，接口不回显正文。服务器现有受保护密钥文件作为初始兼容入口；托管密钥轮换不改员工电脑的全局配置。
- 公司及个人额度按北京时间自然月计算；个人例外可覆盖默认额度，部门仅汇总。迁移时额度为空；0 表示停止后续请求。达到80%提醒，达到额度阻止下一次模型请求，已发送请求继续完成。
- 使用峰时价格：未缓存输入、缓存输入及输出分别计费；推理包含在输出中，不重复收费。单价和配置版本随请求保存，展示为预估费用，不等于供应商账单。
- 每次前台、压缩、标题、记忆和连接测试请求计入独立账本。删除会话不退款；已有历史缺少明细时不补造费用。只报告总 Token 时保留这个已知数量，以最高单价估算待核算费用；完全未知时按受控请求上限保守估计。
- 已发送但未得到可靠用量的请求保持待核算，服务重启不计零。原生记忆及标题不会增加聊天或任务数量。

## 运行与队列

默认1个执行名额；只有维护侧完成实际容量验证才能提高管理员可配置上限。容量证据仅对应验证时的部署主机，恢复、换机及硬件变化后重新校准。

同一用户最多1个运行；同一用户按提交顺序执行，不同用户按最近执行顺序轮换。默认总等待100、每人等待2、最长1800秒；管理员可降低这些限制。排队时间与开始时间分开，等待可取消且不产生模型费用。

排队出队时检查账号、模块、模型、推理档位及当前预算。撤权后即使马上恢复权限，也不自动复活旧运行。重启保留等待队列，执行中的请求按中断恢复处理，不自动重放。背景整理按用户隔离，与前台共用请求名额。

## 接口与持久化

- 管理员：`GET /api/admin/ai-config`、`PUT /api/admin/ai-config/{section}`、`POST /api/admin/ai-config/credential`、`POST /api/admin/ai-config/test`、`GET /api/admin/ai-usage`、`GET /api/admin/ai-queue`。
- 本人模型和额度：`GET /api/me/ai-models`。执行接口增加可选 `model`／`effort`，既有调用未传时使用管理员默认值。运行记录增加 queued 状态、queued_at 及实际模型／档位／配置版本；停止和事件接口继续复用。
- core16新增配置、凭据索引和请求账本；core17增加持久队列。密钥文件、数据库数据及配置纳入既有私密备份与恢复，恢复目标仍须为空且环境身份匹配。
