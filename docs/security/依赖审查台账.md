## 复核命令

- 前端与 Node 依赖：`npm audit`
- Python 当前环境：`uvx --from pip-audit pip-audit --path .venv\\Lib\\site-packages`
- 仓库只读门禁：`npm run security:check`

网络漏洞库会持续变化。任何依赖新增或锁文件变化都必须重新执行审计并更新本台账。
