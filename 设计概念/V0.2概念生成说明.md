# V0.2 概念生成说明

## 生成方式

- 模式：内置 Image Gen。
- 类型：`ui-mockup` 和 `precise-object-edit`。
- 参考：用户提供的 Codex/ChatGPT 侧栏、聊天/工作切换、工作输入框和个人资料菜单截图，以及 V0.1 任务工作台概念。
- 原则：参考交互层级和空间逻辑，不复制产品品牌、名称和标志。

## 主会话提示词

设计企业 AI 中台 V0.2 完整主屏，让每位员工感受到自己拥有一个长期存在的个人 AI 智能体。会话是默认体验，任务是工作模式中创建的持久执行对象。

左侧固定为“新聊天、知识、自动化、任务看板”四个一级入口，下方显示置顶和最近会话，底部只保留个人资料入口。主区域顶部显示“聊天 / 工作”，工作模式中以自然会话呈现用户要求、智能体回复、五步执行计划、需求诊断卡和 ChangeSet 审批；复杂工作留在会话内，任务可跳转任务看板。保持 Codex 式克制、留白和清晰层级，不采用原 V0.1 的四列任务看板作为默认首屏。

## 知识页面提示词

保持同一应用外壳，选择“知识”。主区域顶部显示“个人知识 / 公共知识”，个人知识选中。使用知识列表、Markdown 正文和元数据三部分呈现可确认、可导出、可追溯的个人知识，不把公共知识混入个人列表。

## 自动化页面提示词

保持同一应用外壳，选择“自动化”。主区域顶部显示“Skills / Workflows”，Skills 选中。使用列表与详情呈现 Skill 版本、输入、输出 Schema、关联 Workflow、测试记录及发布操作，不使用卡片网格。

## 任务看板提示词

保持同一应用外壳，选择“任务看板”。主区域顶部显示“任务管理 / 运行记录”，任务管理选中。使用任务表格和右侧详情呈现来源会话、状态、当前步骤、知识引用、Skill、Workflow、检查点和 ChangeSet，并提供“返回会话”。

## 个人资料菜单提示词

在个人资料入口上方打开紧凑菜单，只显示“个人资料、使用情况、系统设置、退出登录”。系统设置不得成为独立侧栏入口。

## 视觉约束

- 淡蓝灰侧栏、真白主区域、炭黑文字、钴蓝选择与主操作。
- 绿色只用于完成，琥珀色只用于等待。
- 细边框、小圆角、轻阴影、清晰中文排版。
- 所有正式交互和文字未来由 React 代码实现。
- 禁止营销页、虚假指标、科幻光效、玻璃拟态、装饰渐变、卡片堆砌和无关一级菜单。
